# GAME PARK - ゲーム強化版

## 内容
- 既存のGAME PARKのデザイン・検索・カテゴリ・お気に入り機能を維持
- 50種類以上のプレイ可能タイトルを収録
- ミニゲーム共通の見た目、ボタン操作、スマホ表示を改善
- 一部チャレンジゲームにライフ、レベルアップ、コンボ、ベストスコア保存を追加
- ベストスコアはブラウザ内に保存されます

## GitHub Pagesへの反映
1. ZIPを解凍
2. `GAME_PARK` フォルダ内の `index.html` `style.css` `games.js` をGitHubリポジトリの一番上（root）にアップロード
3. 同名ファイルを置き換えてコミット
4. GitHub Pagesを再読み込み

※ベストスコアは利用しているブラウザごとに保存されます。
