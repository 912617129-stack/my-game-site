# GAME PARK

Poki風の無料ブラウザーゲームポータルです。

- 10カテゴリー・100タイトルのカタログ
- 検索、お気に入り、カテゴリー切替
- サイト内のゲーム画面・全画面表示
- オリジナルのミニゲーム20種類をプレイ可能

## プレイ可能なゲーム

数字マージ、メモリーマッチ、反射神経テスト、じゃんけん、数字当て、連打チャレンジ、三目並べ、ジャンプランナー、ターゲットタップ、モグラたたき、ナンバーパズル、カラータッチ、バスケットチャレンジ、PKチャレンジ、スペースシューター、カーレーン、トレジャーハンター、ファンタジークエスト、ファームライフ、サイコロバトル。

残りのタイトルは追加準備中です。第三者のゲームを掲載する場合は、制作者の許可と利用条件を確認してください。

## 公開方法

GitHub Pages のリポジトリ直下に `index.html`、`style.css`、`games.js` をアップロードしてください。
