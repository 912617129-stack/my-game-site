# GAME PARK

ブラウザで遊べるゲームポータルです。`index.html` を開くか、GitHub Pagesへアップロードして遊べます。

## 今回の本格ゲーム
- **SKYLINE KART CHALLENGE**：6台対戦・3周レース・アイテム・ターボ・コイン・ガレージ強化
- **NINJA LEGENDS**：全5ステージ・敵との戦闘・手裏剣・巻物収集・ボス門・コイン・道場強化

ゲーム一覧は100タイトルありますが、現時点ですべてが同じ完成度の本格ゲームになったわけではありません。今後、残りのタイトルもジャンルごとに専用ルール・ステージ・成長要素を持たせて作り込みます。

## 操作
各ゲーム内に表示される操作説明を確認してください。PCとスマートフォンの両方に対応した操作を用意しています。
