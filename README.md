# GAME PARK 全タイトル強化版

- 100タイトルすべてにプレイ可能なジャンル別ゲームエンジンを割り当て
- 10ジャンル（アクション、レース、パズル、シューティング、冒険、RPG、スポーツ、ホラー、シミュレーション、カジュアル）ごとに操作と攻略を変更
- ステージ進行、ライフ、スコア、ベストスコア保存を搭載
- キーボードと画面ボタン／タップ操作に対応
- ベストスコアはブラウザのローカル保存

## GitHub Pagesへの反映
1. ZIPを解凍
2. `GAME_PARK` 内の `index.html`、`style.css`、`games.js` をリポジトリのルートにアップロード
3. 同名ファイルを置き換えてコミット
4. 公開サイトを再読み込み

※ゲーム内容はオリジナルのブラウザゲームです。既存ゲーム作品のキャラクターや素材は使用していません。
