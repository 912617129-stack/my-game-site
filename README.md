# GAME PARK

Poki風の無料ブラウザーゲームポータルです。GitHub Pagesで公開できます。

## ファイル
- `index.html` : ページ構造
- `style.css` : デザイン
- `games.js` : 100件のカタログ、検索、お気に入り、ゲーム起動処理

## 遊べるゲーム
初期版にはオリジナルのミニゲームを10本収録しています。
数字マージ、メモリーマッチ、反射神経テスト、じゃんけん、数字当て、連打チャレンジ、三目並べ、ジャンプランナー、ターゲットタップ、モグラたたき。

カタログは100タイトルですが、残り90タイトルは追加準備中の表示です。実際の第三者製ゲームを掲載する場合は、制作者の利用規約・埋め込み許可・ライセンスを確認してください。

## GitHub Pagesで更新する
1. ZIPを展開します。
2. GitHubの `my-game-site` リポジトリを開きます。
3. `Add file` → `Upload files` を選びます。
4. 展開したフォルダ内の `index.html`、`style.css`、`games.js`、`README.md` をアップロードします。
5. 既存ファイルと同名のファイルがある場合は、置き換え内容を確認してコミットします。
6. Pagesは `main` ブランチの `/(root)` から公開する設定のままでOKです。

GitHub Pagesの公開反映には数分かかる場合があります。
