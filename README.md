# GAME PARK

Poki風の無料ブラウザーゲームポータルです。

- 10カテゴリー・100タイトルのカタログ
- 検索、お気に入り、カテゴリー切替
- サイト内のゲーム画面・全画面表示
- オリジナルのブラウザーゲーム100タイトルをプレイ可能
- 今回追加した50タイトルは、10種類の基本ルールをテーマ・難易度違いで展開したミニゲームです

第三者のゲームを掲載する場合は、制作者の許可と利用条件を確認してください。

## 公開方法

GitHub Pages のリポジトリ直下に `index.html`、`style.css`、`games.js` をアップロードしてください。
